# gh-steward Agent Plugin

This portable Agent Plugins 1.0.0 package provides focused skills for the `gh-steward` GitHub CLI extension. It does not bundle or install the executable and has no MCP server, app connection, hooks, or credentials.

Install the CLI separately with `gh extension install coreycoto/gh-steward` after a release is available. Verify its version and source with `gh steward version --json`. Follow the skills here only after confirming the CLI target and GitHub account; installing the plugin does not authorize writes.
